# Freie Wohnungen
Alle Objekte werden direkt von uns vermietet. Bewerbung online, Besichtigung nach Absprache, Entscheid in der Regel innerhalb von fünf Arbeitstagen.
Für diese Auswahl ist derzeit nichts frei. Ein Suchabo meldet neue Objekte, sobald sie ausgeschrieben werden.

## So läuft die Bewerbung

### Anfrage
Formular ausfüllen, Objekt auswählen. Kein Login, keine Registrierung.

### Besichtigung
Einzeltermin mit der zuständigen Person aus der Bewirtschaftung — keine Massenbesichtigung.

### Entscheid
Unterlagen einreichen, Antwort innerhalb von fünf Arbeitstagen, Vertrag digital.

## Suchabo
Nichts Passendes gefunden? Wir melden uns, bevor eine Wohnung öffentlich ausgeschrieben wird. Ein Mail, keine Werbung, jederzeit kündbar.
